    Sync your own track

    Drop an audio file and a timing file anywhere on the page, or use the buttons. Without a timing file, the default timeline is stretched to fit the track length.

    LRC (line timing)

    Element names are found automatically in each line. Their times are spread across the line by character position.

    [ti:Track title]
[ar:Artist]
[00:12.40] Hydrogen, helium and lithium
[00:15.10] Carbon, nitrogen, oxygen

    Enhanced LRC (word timing)

    [00:12.40] <00:12.40>Hydrogen, <00:13.05>helium

    JSON

  "events": [ { "t": 12.4, "z": 1 },

  "lines":  [ { "t": 12.4, "text": "…" } ] }
